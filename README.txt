LITTLE KNIGHT CHESS

The app is four files. Keep them together in one folder:
  index.html            the game itself
  lessons.js            every lesson (53 so far, in 6 sections)
  voice.js              the recorded coach voice
  apple-touch-icon.png  the knight icon for the iPad home screen

ON A WINDOWS LAPTOP
  Double-click index.html. It opens in Edge or Chrome.
  Stars and progress are saved in that browser on that laptop.

ON AN iPAD (through GitHub Pages)
  1. Sign in at github.com, click + at the top right, then New repository.
  2. Name it little-knight-chess, choose Public, and click Create repository.
  3. Click "uploading an existing file", drag in all four files, then click Commit changes.
  4. Open Settings, then Pages. Under Branch choose main and / (root), then click Save.
  5. Wait a minute or two. Pages shows the address, which will look like
     https://YOUR-USERNAME.github.io/little-knight-chess/
  6. Open that address in Safari on the iPad, tap Share, then Add to Home Screen.

UPDATING LATER
  When you get new lessons or new voice recordings, you only get new copies of the
  files that changed (usually lessons.js and voice.js).
  On GitHub: open the repository, click Add file, then Upload files, drag in the new
  files and click Commit changes. Files with the same name are replaced.
  The iPad picks up the change within about 10 minutes. Close and reopen the app.
  Stars and progress are kept, because each lesson has a name that never changes.
  The Grown-ups screen shows the lessons version, so you can check it updated.
